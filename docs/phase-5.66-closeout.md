# Phase5.66 — semantic evidence and a measured forward engine

Implementation complete. Statistical status: **no validated edge and no fitted
rule promoted**. Release SHA, exact CI and native deployment evidence are recorded
in the release pull request after publication.

## What changed

Mahalle now provides a dedicated authenticated, schema-bound Grok interpretation
service. UOA validates exact supporting quotes, issuer identity, event, direction,
certainty, clocks and source/model/prompt/schema identities before using it.
A headline being present no longer substitutes for positive interpretation in
the new research arms. Existing live AL/SAT policy and old PAPER records remain
unchanged; this release introduces independently versioned forward research.

A bounded fundamental observer records financials and earnings for the same
first four prospective candidates/day. It preserves fiscal period, currency,
source paths and actual receipt times. Unknown accounting basis/currency blocks
numeric earnings surprise. Financial context is not assumed to predict an
intraday move. Dark-pool/order-book features absent from a packet remain missing.

Four fixed arms compare base flow/price, confirmed positive news, negative/mixed
news veto, and positive news plus nonnegative revenue growth/positive operating
margin. These boundaries are registered hypotheses, not fitted weights.
PENDING waits for evidence until the original entry cutoff. Immutable decisions
must be physically confirmed at least five seconds before the original delayed
entry reference; late/missing evidence is UNKNOWN. Decisions never read future
entry/exit prices. The same complete candidate roster underlies all comparisons;
SKIP contributes cash-zero only in a verified complete universe. Fifteen and
sixty minute results are separate. Eighty complete prospective common sessions
are required for inferential readiness; the engine does not automatically promote.

The existing research page contains a compact expandable section for decisions,
news reasoning/evidence, financial observations, coverage and calibration results.
Private GET routes only read; they never call providers, fit, migrate or create
records. Source packets and provider responses remain private.

## Decisions and remaining evidence

1. Reuse owned Mahalle/Grok and licensed UW rather than buy an unverified feed.
   [External implementation research](phase-5.66-external-research.md) records
   verified references, adopted practices and access/license limitations.
2. Keep news and fundamental components separable so their incremental effect can
   be measured. Unknown data cannot silently count as neutral or profitable.
3. Per-ticker fitting remains blocked where support is inadequate. Repeated
   historical searches cannot manufacture independent evidence.
4. Stock/SPY last-trade reference outcomes are hypothetical research units, not
   executable option returns, NBBO fills or a funded portfolio. Short references
   exclude borrow/locate effects and are not promoted PUT recommendations.

Next: collect genuinely new eligible sessions, compare paired complete outcomes
and missingness by arm/horizon/event/issuer, then preregister any new calibration
before examining its reserved outcomes. No broker or order execution is included.
