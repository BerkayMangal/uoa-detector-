   daily/chain reads, protected Study G access or post-cutoff repair request.
2. Apply candle gates to original identities without replacement. This is not a
   newly signalled 5-minute-chart system, a full fundamental model or current
   news-policy replay. The original 438-candidate support gate stays unchanged.
3. Use calendar feasibility for the common panel, never profitable-subset
   deletion. Unknowns stay unknown. Completed return endpoints and complete
   path risk are distinct measures.
4. Keep five-session resampling as registered and explicitly descriptive. Entry
   cohort sums are not daily account NAV; +5-session exposures can span six
   sessions and share longer dependence.
5. Add concentration/risk interpretation only as labelled post-hoc projections
   of the fixed panel, with all ten horizons/four costs retained and no selector.
6. Preserve sixteen negative-volume source anomalies, including affected paths;
   use OHLC-only references, without a VWAP/liquidity or executable-fill claim.
